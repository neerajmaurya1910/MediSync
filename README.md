
# MediSync

A Distributed Multi-device Triage Ecosystem.

## Structure

- `docs/` - architecture diagrams and triage rules
- `server/` - central sync and coordination service
- `client/` - bedside, nurse-station and mobile apps
- `shared/` - data models and triage scoring logic

## Version Control

This project is managed with Sapling SCM (`sl`) and hosted on GitHub.
